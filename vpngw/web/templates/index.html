Import a tunnel

A WireGuard .conf or OpenVPN .ovpn file. The type is detected. Your provider's routing and DNS directives are neutralised — on this machine those belong to the gateway.

OpenVPN credentials

Only if the config contains auth-user-pass. Stored under /etc/vpngw/secrets/, created mode 0600.

Add a client

The static address of a VM on the client segment. Traffic from an unregistered machine is dropped — unknown means blocked.

Create a pool

A pool is an exit like a tunnel is: it has its own routing table, pointed at whichever member is healthy. When no member is healthy the pool closes — its clients lose the internet rather than falling back to the uplink.

Connect an account

Credentials are written to /etc/vpngw/secrets/ on this machine, created mode 0600. They are never logged, never read back by any endpoint, and never sent anywhere except the provider's own API.

Connecting opens one hole in the firewall: HTTPS to this provider's API host, and nothing else. Removing the account closes it again.

Bulk import

A configuration archive downloaded from any provider — a zip, a folder's worth of files, or a single config. Works for providers with no API at all; the resulting tunnels are identical.
